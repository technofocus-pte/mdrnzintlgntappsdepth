# **Lab 10 - Create apps and data together using vibe (preview)**

## **Exercise 1: Create an app**

1.  Sign in to Power Apps at **https://make.powerapps.com/** with your
    Office 365 tenant credentials.

2.  Ensure that you are in your developer environment - **Dev One**. If
    not, click on the environment selector and select **Dev One**

> ![](./media/image1.png)

3.  At the top, select **Explore vibe coding in Power Apps
    (Preview)** to enable it.

> ![](./media/image2.png)

4.  Select **Try now**.

> ![](./media/image3.png)

5.  Select the **Profile** tab from the left navigation pane (bottom
    left corner of the screen). Check that you are in the **Dev One**
    environment.

> ![](./media/image4.png)

6.  Enter the given prompt in the text box and then select **Generate**.

> **Prompt**: I want to create an app for real estate agents to manage
> real estate showings.
>
> ![](./media/image5.png)

7.  If you are asked to choose the scope of your app, you can choose any
    one from the given suggestions list. Here we are selecting
    **Detailed tracking** and then select **Next**.

> ![](./media/image6.png)

8.  If asked, select Primary view preference. Here we are selecting the
    **Both views** option. Select **Next**.

> ![](./media/image7.png)

9.  If asked, you can select any of the **Property listing** options and
    then select Next. (Here we selected the Property catalog)

> ![](./media/image8.png)

10. Once done, select **Submit responses**.

> ![](./media/image9.png)

11. Agent starts working and assets load.

> ![](./media/image10.png)

12. After waiting for a few minutes, you can see the message, **Task
    completed**.

> ![](./media/image11.png)

13. You see the project, data model, and app preview generated.

> ![](./media/image12.png)

14. Select the **Data** tab.

> ![](./media/image13.png)

15. Select the **Project** tab.

> ![](./media/image14.png)

16. Select the **App** tab again. You can see that the agent has
    generated many different pages. Select **the hamburger menu.**

> ![](./media/image15.png)

17. Check the pages that the agent generated and close the pane.

> ![](./media/image16.png)

18. Select **Publish**.

> ![](./media/image17.png)

19. Select **Publish**.

> ![](./media/image18.png)
>
> ![](./media/image19.png)

20. Close the publish pane.

> ![](./media/image20.png)

## **Exercise 2: Test the app**

1.  Go back to the **Power Apps** portal. Select **Apps** from the left
    navigation pane.

> ![](./media/image21.png)

2.  You can see that the type of the generated app is **Code**.

> ![](./media/image22.png)

3.  Right now, you cannot edit the app once it is published.

> ![](./media/image23.png)

4.  Select **Play**.

> ![](./media/image24.png)

5.  App will open in a new test window. You can see the various pages of
    the app.

> ![](./media/image25.png)

6.  In this app, you can add the property from the **Properties** page
    or add the client from the **Clients** page.

> ![](./media/image26.png)
