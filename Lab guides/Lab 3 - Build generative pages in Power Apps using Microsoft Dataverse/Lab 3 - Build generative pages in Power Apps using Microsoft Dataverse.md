**Lab 3 - Build generative pages in Power Apps using Microsoft
Dataverse**

**Objective**: In this lab, you will learn how to create a Dataverse
table and model-driven app using Microsoft Dataverse table and leverage
Copilot to generate responsive generative pages using natural language
prompts.

## **Exercise 1 - Create a Model-driven app from the Microsoft Dataverse table**

### **Task 1 - Create a Model-driven app**

1.  Sign in to Power Apps at **https://make.powerapps.com/** with your
    Office 365 tenant credentials.

2.  Ensure that you are in your developer environment - **Dev One**. If
    not, click on the environment selector and select **Dev One**.

> ![](./media/image1.png)

3.  From the left navigation pane, select **Tables**.

> ![](./media/image2.png)

4.  Select **+ New table** \> **Create new tables**.

> ![](./media/image3.png)

5.  Select **Start with Copilot**.

> ![](./media/image4.png)

6.  Enter the following prompt and then select **Generate**.

**Prompt**: Create a table named Course Catalog with the following
columns:  
Course ID (Auto Number), Course Name (Text), Course Category (Choice –
Technical, Functional, Compliance, Soft Skills), Course Level (Choice –
Beginner, Intermediate, Advanced), Course Status (Choice – Draft,
Active, Inactive, Retired), Delivery Mode (Choice – Online,
Instructor‑led, Blended, Self‑paced), Duration (Hours) (Number), and
Certification Offered (Yes/No).

![](./media/image5.png)

7.  Copilot generates the table.

> ![](./media/image6.png)

8.  Select the table and then select **View data**.

> ![](./media/image7.png)

9.  You can observe the data in the table. Close the Copilot pane for a
    better view.

> ![](./media/image8.png)

10. Select **Save and exit**.

> ![](./media/image9.png)

11. Select **Save and exit** again.

> ![](./media/image10.png)

12. Now, open the **Course Catalog** table from the list of tables.

> ![](./media/image11.png)

13. Select **Create an app** from the top menu bar.

> ![](./media/image12.png)

14. Name the app as **Learning Offerings**. Select **Create**.

> ![](./media/image13.png)

15. The model-driven app has been created.

> ![](./media/image14.png)

## **Exercise 2 - Create a generative page in a model-driven app**

### **Task 1: Generate a page using natural language**

1.  Open the model-driven app for editing, if it is not already open.

> ![](./media/image14.png)

2.  In the app designer, select **Add page** \> **Describe a page**.

> ![](./media/image15.png)

3.  A full-page generative page experience opens.

> ![](./media/image16.png)

4.  Choose **Tablet** (1024 x 768) screen size.

> ![](./media/image17.png)

5.  Add Course Catalog table by selecting **+** sign **Add
    data** \> **Add table**.

> ![](./media/image18.png)

6.  Select the **Course Catalog** table.

> ![](./media/image19.png)

7.  In the textbox, type a description of the type of page you want to
    create. The description should include functional requirements and,
    optionally, any UX specifications.

> Create a generative page for exploring courses with the following
> features.
>
> UI Theme: Use an elegant, modern design with a blue color palette.  
> The page is customer-facing and should support searching and filtering
> courses by Category, Level, and Delivery Mode.  
> Display key course information including Course Name, Course Category,
> Course Level, Delivery Mode, Duration (Hours), and Course Status.  
> Provide a clean, user‑friendly experience with logical grouping of
> fields, minimal clutter, and responsive interactions to ensure the
> page is visually appealing and easy to use.
>
> ![](./media/image20.png)

8.  The agent begins a multi-step build process that you can observe in
    real time:

> **Thought streaming**: The agent first outlines its interpretation of
> your prompt, listing requirements, assumptions, and an execution plan.
>
> **Code generation**: Next, it writes the underlying code for your page
> based on the plan.
>
> **Transpilation**: The generated code is then transpiled to ensure
> compatibility and proper rendering.
>
> **Final rendering**: Finally, the completed user experience is
> displayed.
>
> ![](./media/image21.png)
>
> ![](./media/image22.png)

9.  The page has been generated by the agent. You can now check the
    functionality of the page.

> ![](./media/image23.png)

10. Filter out the technical courses by selecting **Technical** from the
    drop-down menu.

> ![](./media/image24.png)

11. Only technical courses will be displayed.

> ![](./media/image25.png)

12. Select **+Add page** \> **Describe a page**.

> ![](./media/image26.png)

13. Change the screen size to **Desktop**.

> ![](./media/image27.png)

14. In the text box, enter +++**/**+++ and select **Course Catalog**
    table.

> ![](./media/image28.png)

15. Enter the prompt and then select the send icon.

> **Prompt**: Build a Course Management Dashboard screen – make it look
> professional.
>
> ![](./media/image29.png)

16. You can see that the dashboard has been created.

> ![](./media/image30.png)

17. On the left pane, enter the given prompt to modify the dashboard and
    then select the send icon.

> **Prompt**: Make the dashboard look like a Power BI report.
>
> ![](./media/image31.png)

18. You can see that the agent has now modified the dashboard.

> ![](./media/image32.png)

19. Select **Save**.

> ![](./media/image33.png)

20. Select **Publish**.

> ![](./media/image34.png)

21. Select the **Play** button.

> ![](./media/image35.png)

22. You can test the dashboard.

> ![](./media/image36.png)
>

> Copilot, build a model-driven app, and design generative pages through
